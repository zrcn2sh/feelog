## 1. 프로젝트 개요

**Feelog**는 사용자의 감정을 기록하고, AI로 분석하여 시각화·관리하는 일기/감정 로깅 앱입니다.

- **플랫폼:** Android, iOS, Web
- **테마:** Cupertino(iOS 스타일) 기반, 보라색(#8B5CF6) 프라이머리 컬러, Google Fonts(gaegu)
- **개발:** Nat-dwi @idosquare

## 3. 구현된 기능 요약

### 3.1 인증 (Auth)

- **Google 로그인:** 웹(clientId), Android(serverClientId), iOS 지원, Firebase Auth 연동
- **Apple 로그인:** iOS 13+, Android(WebAuthenticationOptions + Service ID), nonce 기반 재전송 공격 방지
- **로그아웃:** Firebase + Google Sign-In 로그아웃, 로컬 사용자 정보 삭제
- **계정 탈퇴:** Firestore 일기/사용자 문서 삭제 → 모바일 Hive 사용자 데이터 삭제 → Firebase Auth 계정 삭제
- **사용자 프로필:** Firestore `users` 컬렉션에 uid, email, displayName, photoURL, lastLoginAt 등 저장
- **로그인 이력:** `loginHistory` 컬렉션에 로그인 시점·방식 기록

### 3.2 일기 (Diary)

- **일기 작성/수정/삭제:** 날짜별 일기 저장, 수정 모드, 삭제 확인 후 처리
- **플랫폼별 저장:**
  - **웹:** Cloud Firestore (`diaries/{uid}/entries/{dateStr}`)
  - **모바일:** Hive 사용자별 Box (`diaries_{uid}`), Map 형식 저장(TypeAdapter 없이 `toHiveMap`/`fromHiveMap`)
- **데이터 구조:** 날짜, 본문(content), 감정 분석 결과(moodAnalysis), createdAt, updatedAt

### 3.3 AI 감정 분석 (AIService)

- **일기 단건 분석:** Marc Brackett의 Mood Meter 기반 감정 목록(빨강/노랑/초록/파랑 계열) 사용
- **출력:** `MoodAnalysisResult` — emotions(최대 3개), moodWeights, advice(한국어 조언)
- **기간별 분석:** 6개월/1년 구간의 감정 분포를 사분면별로 정리 후 AI에게 조언 요청
- **폴백:** API 실패 시 기본 분석 결과 및 안내 문구 반환, `lastCallUsedFallback` 플래그 제공
- **모델 fallback:** gemini-2.0-flash → gemini-pro → gemini-1.5-pro 순으로 초기화 시도

### 3.4 홈 화면 (HomePage)

- **달력:** 월별 보기, 일기가 있는 날짜 표시, 날짜별 주요 감정(첫 번째 감정) 색상 표시
- **일기 편집기:** 선택한 날짜의 일기 로드/저장, AI 분석 버튼, 분석 중 로딩 표시
- **감정 차트:** 선택한 일기의 감정 분석 결과를 막대/비율로 시각화 (`_buildMoodChart`)
- **기간별 감정 보기:**
  - **6개월(6M):** 최근 6개월 일기 목록, 감정 그리드, 기간별 AI 조언(캐시 및 재분석 조건 처리)
  - **1년(1Y):** 1년 단위 감정 그리드 및 AI 조언
  - **같은 날(SD):** 같은 월·일의 과거 연도 일기 목록
- **월별 일기 개수 차트:** `_getMonthlyDiaryCount`, `_showMonthlyDiaryChart`
- **사용자 메뉴:** 프로필 표시, 로그아웃, 계정 탈퇴(확인 다이얼로그)
- **디버그:** Hive 데이터 확인용 `_showHiveDataDebug` (개발 시 활용)

### 3.5 온보딩 및 설정

- **온보딩 모달:** 첫 로그인 시 한 번만 표시(사용자별 SharedPreferences), 6M/1Y/SD 버튼 설명, 일기 데이터 안내(기기 저장·복구 불가)
- **설정 화면:** 화면 모드(자동/라이트/다크), 데이터 옮기기(백업 내보내기·가져오기), 계정 탈퇴(홈 진입 시에만 표시)
- **다크 모드:** 시스템 설정 따르기(자동) / 라이트 / 다크 세 가지 옵션, `AppTheme` + `WidgetsBindingObserver`로 시스템 밝기 반영
- **앱 설정:** `AppSecret`(Gemini API 키, Google Web Client ID), `AppVersion`(버전, 개발자명)
- **플랫폼 유틸:** `PlatformUtils` — isWeb, isMobile, isAndroid, isIOS

### 3.6 로컬 저장소 (LocalDiaryService, 모바일)

- **Hive:** 사용자별 `diaries_{uid}`, `period_analysis_{uid}` Box
- **일기 CRUD:** saveDiary, loadDiary, deleteDiary, getAllDiaryDates, getDiaryMainEmotions
- **기간/조건 조회:** getDiariesByDateRange, getDiariesByMonthDay
- **기간별 분석 캐시:** savePeriodAnalysis, loadPeriodAnalysis
- **백업/복원:** `exportAllData()` — 일기·기간 분석 전체를 JSON 호환 Map으로 반환; `importAllData(map)` — 동일 형식으로 Hive 복원(같은 키는 덮어씀). 모바일 전용 `backup_restore_io.dart`에서 파일 공유(share_plus)·파일 선택(file_picker) 및 선택적 암호화(AES-256-CBC) 지원
- **초기화:** `initialize(userId)` — 웹 스킵, 사용자별 Box 전환 시 기존 Box 닫기
- **계정 탈퇴 시:** `deleteUserData(userId)` 로 해당 사용자 Hive 데이터 삭제

## 5. Firebase / 외부 연동

- **Firebase:** `firebase_core`, `firebase_auth`, `cloud_firestore`, `flutterfire_cli`로 옵션 생성
- **Firestore 구조:**
  - `users/{uid}` — 사용자 프로필
  - `diaries/{uid}/entries/{dateStr}` — 일기 (웹)
  - `diaries/{uid}/period_analysis/{key}` — 기간별 분석 캐시 (웹)
  - `loginHistory` — 로그인 이력
- **Apple 로그인 (Android):** Service ID `com.idosquare.feelog.service`, Redirect URI (Firebase Auth handler) 사용
- **문서:** `docs/` 내 Firebase/Google/Apple 로그인 및 iOS 빌드 체크리스트 등 정리됨
